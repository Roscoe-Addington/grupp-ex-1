Hur fungerar arv i CSS? Ge ett exempel från er egen kod?
Arv fungerar så att man till exempel sätter färg på föräldern och barnen ärver, så länge baren inte sätter egenskapen sjäv.
Ex: i vår kod är footer där har vi satt color och barnen får också den färgen.

Vad är den största skillnaden mellan Flexbox och CSS Grid, och när ska man använda vilket verktyg? 
Flexbox är endimensionellt. Det är utformat att lägga element i en riktning åt gången, tex rad eller kolumn. På vår sida använde vi Flexbox när vi skulle rada upp vara aktiviteter om pannkokor.
CSS är två dimensionellt och kan hantera både rader och kolumner samtidigt. Vi ville ha fasta kolumner på våra events, för vi behövde både rader och kolumner.
